# 로컬 과정 확인 도구

`apps/api/tools/verify_practice_course.py`는 새 실습 형식을 세 난이도로 실제 저장·실행·제출하는 개발용 도구다. DB에 완료 상태를 직접 넣지 않는다. 일반 pytest 실행에는 포함되지 않는다.

## 실행

WebLink의 api, web, postgres, worker, learning-runner와 실행 이미지가 준비된 로컬 환경에서 저장소 루트 기준으로 실행한다.

```powershell
python apps/api/tools/verify_practice_course.py --run-local --output "$env:TEMP\weblink-course-qa"
```

- localhost HTTP 주소만 허용하며 기본 주소는 `http://localhost:8000`이다.
- 확인 전용 `qa-course-…@example.com` 계정을 수준별로 만든다. 기존 사용자 계정과 진도는 수정하지 않는다.
- 출력 폴더는 저장소 밖이어야 한다. `practice-course-private.json`에는 확인 계정의 로그인 정보가 있으므로 커밋하거나 공유하지 않는다.
- `practice-course-report.json`은 미션별 저장 버전과 실제 검사 결과를 기록한다. 공개 보고서에는 비밀번호나 세션을 넣지 않는다.
- 같은 출력 폴더로 실행하면 확인 계정을 재사용한다. 이 도구는 참고 답안으로 정상 흐름을 검사하므로 직접 편집 중인 확인 계정과 공유해서 사용하지 않는다.
- `--levels BEGINNER`처럼 범위를 줄일 수 있다. 보고서는 해당 실행에서 지정한 수준의 결과로 다시 작성한다.

이 검사는 브라우저 조작·사용성·학습 효과의 증거가 아니다. M11 재현본은 의도한 실패 항목이 있어야 하며 수정본은 통과해야 한다. 네트워크/자원 장애가 발생하면 성공으로 대체하지 않고 실행을 중단한다.

## 이번 검증에서 추가 확인한 흐름

- 입문 경로의 M05/M07/M10 선택 응용 과제를 실제 실행했다.
- 선수 답안이 바뀌면 후속 완료 상태를 자동으로 최신이라고 간주하지 않는다. M05 변경 뒤 M06, M07 변경 뒤 M08, M10 변경 뒤 M11을 다시 확인해야 했다.
- M10/M12에서 게시판·재고·메모장·할 일 앱을 ZIP으로 내보내고 반복 요청의 프로젝트 재사용을 확인했다.
- 게시판은 로컬 브라우저에서 두 글 등록·빈 입력 거절·새로고침·API 재시작 후 유지, 메모장은 등록·새로고침 복원을 확인했다.

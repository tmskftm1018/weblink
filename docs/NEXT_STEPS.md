## 2026-10-20 추가 반영 · 개인 프로젝트·출처·실행 구성·브리지 복귀

- M10/M12 본 과제 또는 전이를 현재 저장본으로 확인한 뒤 개인 프로젝트로 가져오는 API/UI를 구현했다. 기존 프로젝트의 파일/팀원/버전/ZIP 기능과 파일 생성 서비스 내부를 재사용한다. 일반 ZIP 가져오기는 같은 파일 생성 helper의 기본 commit=True 동작을 유지한다.
- 새 LearningProjectExport와 추가형 migration 0047: enrollment/node/field마다 한 프로젝트만 만들고 최초 학습 hash/version과 프로젝트 revision/hash를 기록한다. PostgreSQL 등록 행 잠금과 고유 제약으로 반복 요청에 사본이 늘어나지 않도록 구성했다. 프로젝트·출처·연결·RECORDED 증거는 한 트랜잭션으로 저장한다. 프로젝트를 삭제했거나 소유권이 달라졌다면 자동 재생성하지 않고 안내한다.
- 다시 누르면 기존 본인 소유 프로젝트를 연다. 이후 학습 답안이나 프로젝트 변경은 자동 덮어쓰지 않으며 학습 원본과 달라졌다는 안내를 프로젝트 화면에 표시한다. 학습의 통과 판정을 새 프로젝트 실행 통과로 복제하지 않는다.
- 생성 파일: 원본 API, import/export만 덧붙인 React App.jsx와 원본 JSX, 한국어 README, Vite·React 진입 파일, Python/Node Dockerfile, compose.yaml, 출처 JSON 등이다. 사용자 코드와 생성한 앱을 main API에서 실행하지 않는다. 로컬 포트는 화면 5174/API 8081이며 SQLite는 별도 named volume으로 보관한다. WebLink의 기존 Python 실행 버튼으로 이 전체 앱을 실행한다고 안내하지 않는다.
- 처음 만든 프로젝트만 기본 학습 연결에 사용한다. 이후 생성한 학습 프로젝트는 사용자가 명시적으로 연결을 바꿀 수 있다. 다른 사용자/팀 편집 권한만 있는 프로젝트로 연결하지 않는다. 브리지 진행 중 연결 변경은 차단한다.
- 브리지는 연결 프로젝트의 확정 revision에서 파일·줄을 선택하고 현재 위치를 보관한 뒤 추천 개념/기초 예제를 표시한다. 복귀 시 원래 revision/file/line을 읽기 전용 Monaco에서 연다. 최신 프로젝트 편집기를 여는 동작은 별도이며 원래 snapshot으로 파일을 덮어쓰지 않는다. 미저장 내용과 리비전으로 확정하지 않은 초안은 브리지 원점에 포함하지 않는다.
- M10에는 HTTP/React/SQL, M12에는 디버깅 브리지를 추천했다. 기초 예제를 보는 것은 미션 완료나 자동 진도 증가가 아니다. 활성 브리지를 마친 뒤 미션을 이동하도록 안내한다. 서버의 기존 origin 보존/복귀 검증을 재사용한다.
- Monaco에 선택 줄 이동/커서 관찰을 추가하고 학습에서 최신 프로젝트 편집기로 이동할 때 경로와 줄을 전달한다. 원래 파일이 삭제됐다면 첫 파일을 열고 안내한다. 기본 프로젝트 진입은 기존 개요 화면을 유지한다.
- 전체 학습 기록 JSON에는 프로젝트로 가져온 출처 revision/hash도 포함한다. 개인 프로젝트 생성·브리지 접근은 계정별 등록과 OWNER 권한으로 제한한다.
- 확인: 웹 TypeScript/Vite build 성공(기존 Monaco 큰 청크 경고), 새 Python/변경 학습 서비스 Ruff 및 Python 구문 컴파일, 커리큘럼 구조 검사 통과. Docker 이미지 재빌드와 서버 시작을 수행했다. 자동 테스트와 실제 프로젝트 생성·동시 요청·ZIP 앱 실행·브리지 복귀·권한/E2E 검증은 수행하지 않았다.

- M10/M12의 프로젝트 변경 비교·반영을 연결했다. 관리 대상은 App.jsx, API, 원본 JSX와 출처 JSON 네 파일이다. 나머지 프로젝트 파일과 실행 설정은 보존한다.
- 이전에 가져온 학습 기준/현재 서버 프로젝트/새 학습 원본을 비교하고 양쪽 변경은 파일별 KEEP_PROJECT 또는 USE_LEARNING 선택을 요구한다. 프로젝트에서 지운 파일도 변경으로 취급한다. 미전송 로컬 폴더와 다른 창의 미저장 내용은 비교 대상이 아니다.
- 미리보기의 초안 version과 전체 프로젝트 hash, 현재 학습 version을 적용 시 다시 확인한다. 등록/초안 행 잠금·낙관적 조건 갱신을 사용한다. 동시 revision 저장의 고유 제약 충돌은 rollback 후 409로 안내한다.
- 반영 전 서버 초안을 revision으로 보관하고 변경 후 revision/RECORDED 출처/기준을 한 트랜잭션에 기록한다. 코드 변경이 없고 이미 같은 기준을 확인했다면 중복 기록을 만들지 않는다. 프로젝트 실행 통과를 자동 부여하지 않는다.
- migration 0048은 nullable baseline_files JSON만 추가한다. 기준은 병합 결과가 아닌 새 학습 원본이다. 이번에 유지한 프로젝트 수정을 다음 반영에서 덮어쓰지 않도록 계속 로컬 변경으로 취급한다. 이전 export는 최초 revision에서 기준을 읽으며 이 기준이 없으면 반영을 보류한다.
- M06~M12의 계정별 최근 30개 실행 목록과 기존 실행 ID 조회/기다리기를 연결했다. 결과 다시 열기는 새 실행을 큐에 넣지 않는다. 현재/과거 답안 구분, 기다리기 중지 후 재조회, 개별 JSON 내려받기를 제공한다. M04/M05 직접 실행에는 이 큐 기록 목록이 없다.
- 현재 코드/답안과 다른 결과는 과거 저장본으로 표시한다. 실행의 순진한 UTC timestamp는 API에서 UTC offset을 붙여 날짜 표시 오해를 줄였다.
- 확인: TypeScript/Vite build, 변경 학습 Python Ruff/구문 컴파일, Docker 서비스 시작, DB head 0048과 readiness를 확인했다. 기존 Monaco 큰 청크 경고는 남아 있다. 자동 테스트를 새로 추가/실행하지 않았고 실제 병합/충돌/복원/학습 완주는 실행 검증하지 않았다.


## 사용자 요청으로 확인용 예제 계정에서 추가 확인

기존 사용자 계정과 진도를 수정하지 않고 별도 로컬 예제 계정을 만들었다. 점수/완료 상태를 DB에 직접 넣지 않았으며 실제 HTTP 저장·실행·제출로 준비했다. 계정 비밀번호·세션과 임시 예제 준비 스크립트는 저장소에 포함하지 않는다.

- M01~M12를 실제 API로 순서대로 저장/실행/제출하여 12개 완료를 확인했다. M04 8개, M05 본/도서 전이 각 8개, M06 4개, M07 본/행사 전이 각 9개, M08 5개, M09 12개, M10 본/재고 전이 각 14개, M11 수정본 14개와 실패 재현본 11/14, M12 메모/할 일 각 14개 관찰 결과를 확인했다. M11의 재현본은 일부 항목 실패가 정상인 예제다.
- 같은 M10/M12 프로젝트 가져오기를 다시 호출해 created=False로 기존 프로젝트 재사용을 확인했다.
- M12 학습 코드와 프로젝트 API를 각각 수정하여 CONFLICT를 관찰했다. 프로젝트 API 유지 선택으로 반영한 뒤 직접 추가한 주석과 별도 문서 파일이 유지되는 것을 확인했다. 오래된 미리보기 재적용은 409로 차단됐다. 다음 학습 변경에서도 이전에 유지한 프로젝트 수정이 CONFLICT로 남는 것을 확인했다.
- 메모장 프로젝트를 명시적으로 연결하고 B-DEBUG 진입/복귀로 같은 revision/file/5번 줄이 복구되며 프로젝트 파일은 바뀌지 않는 것을 API로 확인했다. 저장된 실행 GET은 14개 관찰 결과를 반환했다.
- 브라우저에서 확인용 계정의 12/12 표시, M12의 현재/이전 실행 선택, 변경 비교와 파일 충돌 선택 화면을 확인했다.
- 생성된 프로젝트 파일을 별도 로컬 Docker Compose로 빌드·기동했다. 메모장 화면에서 입력→저장→목록 표시→브라우저 새로고침 후 데이터 유지를 확인했다. 이 구성은 localhost:5174(화면)/8081(API)이며 WebLink 서버와 별도로 실행한다.

이 기록은 한 확인용 계정과 준비한 예제의 제한된 확인이다. 모든 미션을 브라우저 폼으로 처음부터 작성한 완주, 동시 사용자/권한 공격·격리 한도·장치 재부팅·모바일·임의 학습 코드까지 검증한 것은 아니다. pytest 전체 회귀 검사를 새로 실행한 기록도 아니다. 과정은 partial로 유지한다.

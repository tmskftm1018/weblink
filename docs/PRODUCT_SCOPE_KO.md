# WebLink의 목적과 개발 범위

기준일: 2026-10-29. 교수님 피드백과 사용자의 범위 조정을 반영한다. 이전 계획에서 실제 운영이나 외부 서비스 연동을 우선하는 항목보다 이 문서를 우선한다.

## 한 문장 소개

WebLink는 코드를 배운 사람이 **화면·API·데이터베이스를 연결해 하나의 앱을 완성하는 과정**을 연습하는 교육용 사이트다.

## 해결하려는 문제

문법을 배우거나 AI로 코드를 얻어도, 그 코드를 어디에 넣고 어떻게 실행하며 다른 구성 요소와 연결하는지는 막막할 수 있다. 화면의 저장 버튼이 어떤 요청을 보내고, 서버가 무엇을 검사하며, 데이터가 어디에 남는지 이해해야 실제 앱을 만들 수 있다.

WebLink의 수업은 이 연결 과정을 작은 미션으로 나누고 실행 결과를 직접 확인하게 한다. AI를 사용한다면 학습자가 자신의 웹사이트나 CLI에서 사용하며, WebLink 학습에 AI API 연결은 필요하지 않다.

## 대상과 학습 결과

- 대상: 코드 기초를 접했지만 화면·서버·DB를 연결한 앱을 혼자 완성하기 어려운 학습자.
- 결과물: 입력·조회·저장이 되는 작은 웹 앱과 그 동작을 확인한 학습 기록.
- 설명할 수 있어야 할 것: 입력이 요청으로 바뀌고, 서버 검증을 거쳐 DB에 저장되며, 다시 화면에 표시되는 흐름.
- 다른 문제에도 적용할 것: 게시판에서 익힌 연결을 메모장·할 일 같은 별도 문제에 적용하기.

## 대표 시연 흐름

대표 사례는 게시글을 저장하는 작은 앱으로 통일한다. 다음은 시연 목표이며, 새 난이도별 전체 시나리오가 이미 검증됐다는 뜻은 아니다.

1. 배우고 싶은 분야(웹 화면·서버/API·데이터베이스)와 수준을 선택하고 이번 미션의 목표와 성공 조건을 읽는다.
2. React 화면에서 제목과 내용을 입력한다.
3. 버튼을 누르면 FastAPI로 요청이 전달되는 것을 확인한다.
4. 서버가 잘못된 입력을 거절하고 정상 입력을 SQLite에 저장하는 것을 확인한다.
5. 다시 조회했을 때 저장된 글이 나타나는지 확인한다.
6. 연결 오류나 잘못된 입력 사례를 고치고, 같은 원리를 다른 작은 앱에 적용한다.

발표에서는 기능 목록보다 이 흐름의 전후 차이를 보여준다. 학습 전에는 따로 있던 화면·서버·DB를 학습 후 하나의 동작으로 연결할 수 있다는 점이 핵심이다.

## 개발 우선순위

1. **수준별 수업 완성:** 입문자는 충분한 설명과 작은 단계, 기본 수준은 부분 구현, 경험자는 직접 설계와 응용을 제공한다. 현재 구현된 시작 코드·안내·필수 전이 범위를 바탕으로 수업 내용과 평가를 완성한다. 관심 과목은 분야별로 복수 선택하며 해당 미션과 복습을 찾는 데 사용한다. 공통 미션·선수 조건·기존 완료 기준은 유지한다.
2. **학습 흐름 정리:** 현재 수업·과거 기록·기초 복습의 관계를 정리하고, 지금 할 일과 완성할 결과물이 분명하도록 수업 설명을 다듬는다.
3. **핵심 시연 검증:** 코드 작성 → 실행 → 결과 확인 → 오류 수정 → 앱 완성까지 로컬 환경에서 확인한다. 저장과 복구도 이 학습 흐름을 지키는 범위에서 검증한다.

프로젝트 작업 공간은 배운 코드를 이어서 수정하고 결과물을 보관하는 공간이다. 팀 관리·작업 보드·버전 관리는 보조 기능이며 발표의 주제로 확대하지 않는다.

## 이번 범위에서 보류할 작업

- Google 로그인·가입, Google Drive·Sheets 연동의 추가 개발과 실제 계정 연동 확대.
- GitHub push·양방향 동기화 등 외부 저장소 연동 확대.
- SMTP 초대 메일 설정, 외부 공개 배포, 다중 장치 운영 환경 구성.
- 글자 단위 실시간 공동 편집과 예약 동기화 등 확장 기능.
- 공개 운영을 위한 부하·운영 체계 구축. 로컬 코드 실행의 기본 격리·권한·데이터 보호는 유지한다.

이미 구현된 연결 기능이나 사용자 데이터는 이번 결정만으로 삭제하지 않는다. 기존 기능은 보존하되 새 작업과 시연의 필수 조건에서 제외한다. 화면 디자인과 배치 변경은 친구가 담당하며, 별도 요청 없이 수정하지 않는다.

## 교수님께 설명할 때

> “문법이나 AI로 얻은 코드만으로는 실제 앱을 완성하기 어렵다는 문제에서 출발했습니다. WebLink는 화면의 입력이 API를 거쳐 DB에 저장되는 과정을 미션으로 연습하는 교육용 사이트입니다. 학습자는 자신의 수준에 맞는 도움을 받으며 작은 앱을 만들고, 실행 결과와 오류를 확인한 뒤 다른 앱에도 같은 연결 원리를 적용합니다.”

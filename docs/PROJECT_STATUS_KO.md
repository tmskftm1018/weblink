# WebLink 진행 상황

마지막 정리: 2026-10-01

## 만들고 있는 제품

WebLink은 코딩 문법을 익히는 데서 멈추지 않고, 프로젝트를 API·데이터베이스·외부 앱과 연결하는 과정을 배우는 교육용 개발 플랫폼이다. 블록 활동으로 시작한 코드를 실제 프로젝트로 옮기고, 저장·실행·디버깅·데이터 연결까지 이어가는 방향으로 개발 중이다.

## 현재 구현된 기능

- 이메일 가입 및 로그인, 세션 관리
- 5개 학습 코스, 총 37개 수업과 사용자별 진행도 저장
- 코드 블록 순서 조립, 사용 블록 표시, 오답 힌트
- 프로젝트 생성, 파일 편집, 초안 저장, 리비전 및 명명된 버전 관리
- 프로젝트 목록에서 실행 가능한 SQLite 독서 기록 예제를 한 번에 만들고, 여러 파일로 데이터베이스 사용 흐름을 확인
- 프로젝트 파일 탐색기에서 폴더를 만들고 접고 펼치며, 파일을 끌어 폴더 간 이동하거나 프로젝트 루트로 다시 꺼낼 수 있음. PC의 UTF-8 텍스트 파일과 폴더도 루트나 폴더에 끌어 넣을 수 있고, 폴더 구조와 빈 폴더를 유지함. 파일당 200KB·전체 1MB·최대 50개 제한과 비밀 파일 차단을 적용. 폴더 안에 바로 새 파일을 추가하고 빈 폴더는 `.gitkeep` 파일로 ZIP·Git 저장 시 유지
- VS Code 기반 Monaco 코드 편집기: 문법 강조, 줄 번호, 파일 탭, 검색, 저장·실행·탭 닫기 단축키
- 파일 탐색기에서 새 파일을 추가하고 열어 둔 파일 탭을 선택하거나 닫을 수 있음
- 파일 탐색기에서 파일 이름을 바꾸거나 삭제할 수 있고, 연결한 로컬 폴더에도 같은 파일 작업을 반영. 같은 이름이 있으면 `도구 (2).py`처럼 번호를 붙이며, 실행 시작 파일 `main.py`도 이동·이름 변경·삭제 가능
- 폴더 이름을 바꾸거나 삭제할 수 있음. 이름 변경 시 내부 파일 경로와 연결한 컴퓨터 폴더도 함께 갱신하고, 삭제 시 안의 프로젝트 파일과 빈 폴더를 정리. 확인창에서 삭제 범위를 먼저 안내
- 프로젝트 소유자는 가입된 WebLink 이메일로 팀원을 추가하고 편집자 또는 보기 전용 권한을 지정하거나 제거 가능. 다른 팀원의 저장·프로젝트 정보·권한을 10초 간격과 창 복귀 시 확인해 화면에 반영하며, 내 코드가 저장되지 않은 상태면 덮어쓰지 않고 최신 초안 확인을 안내. 초대 이메일과 글자 단위 실시간 공동 편집은 아직 지원하지 않음
- 프로젝트 소유자는 이름과 설명을 수정하고, 팀원의 편집자·보기 전용 권한을 필요할 때 바꿀 수 있음. 이름과 설명 수정은 프로젝트 초안 버전을 건드리지 않음. 접근이 해제되거나 프로젝트가 삭제되면 저장되지 않은 코드를 복사할 수 있도록 안내하고 프로젝트 목록으로 이동 가능
- 프로젝트 안에 할 일·진행 중·완료 작업 보드를 제공. 제목·설명·담당자·우선순위·마감일 필터와 ‘내 작업’ 보기를 지원하고, 전체 완료율·진행 중·기한 초과 개수를 요약 표시. 내 작업 중 기한 초과·7일 내 마감 항목으로 바로 이동할 수 있음. 최근 100개 활동을 알림 패널에서 확인하고 항목을 누르면 해당 작업으로 이동. 읽음 상태는 현재 브라우저의 사용자·프로젝트별 로컬 저장소에 저장하므로 다른 브라우저나 컴퓨터와 공유되지 않음. 작업별 체크리스트(최대 30개), 댓글, 생성·상태·담당자·우선순위·마감일·체크 항목 변경 기록을 확인. 댓글과 기록은 프로젝트 팀원에게 보이고, 댓글 작성과 작업 관리는 편집자·소유자만 가능. 작업은 프로젝트당 200개 제한이며, 팀원 제외 시 담당 해제 기록과 함께 담당자 없음으로 전환
- 프로젝트 첫 화면에 소개·최근 활동·파일/작업/팀원/저장 버전 요약을 보여주는 대시보드를 제공. 최근 활동을 누르면 관련 작업 기록으로 이동하며 읽음 상태를 작업 보드 알림과 공유. 루트 `README.md`의 Markdown과 안전 허용 목록에 포함된 기본 HTML을 미리 보고 편집기로 이동할 수 있으며, README가 없으면 소개와 파일 목록을 담은 초안을 만들 수 있음. 스크립트·이벤트 속성·임의 스타일은 실행하지 않음. 코드 편집·작업 보드·팀 관리·저장 위치를 별도 구역으로 열 수 있어 한 화면에 모든 도구가 길게 쌓이지 않으며, 구역을 바꿔도 작업 보드 입력과 열린 패널 상태는 유지
- 학습 화면의 수업 본문 폭을 읽기 좋은 범위로 제한하고 코스 목록은 화면 안에서 스크롤되도록 구성. 연결 화면도 프로젝트 화면과 같은 페이지 폭·여백을 사용하며, 스프레드시트 ID와 범위 입력을 넓은 화면에서는 나란히 표시하고 모바일에서는 세로로 배치
- 보기 전용 계정은 화면과 API 양쪽에서 파일 변경·저장·실행·버전 변경을 제한. 편집자와 소유자는 초안 저장·버전 관리·실행 가능하고, 프로젝트 삭제와 팀원 관리는 소유자만 가능
- 저장 버전마다 만든 사람과 저장 날짜를 표시. 오래된 화면에서 복원을 요청하면 최신 초안 버전을 서버에서 대조해 팀원의 최근 저장 내용을 덮어쓰지 않도록 충돌 안내
- 루트 `main.py`가 없으면 실행 버튼을 비활성화하고 복구 방법을 안내. 이동·이름 변경·삭제 전에도 실행에 미치는 영향을 확인
- 실행 결과 패널 닫기, 디버깅 가설 저장 버튼 안내, 리비전 내역을 화면에서 숨김
- 프로젝트 목록 화면을 저장 위치 안내, 검색, 생성·가져오기, 프로젝트별 저장소 상태를 확인하는 작업 공간으로 개편
- Chrome·Edge에서 프로젝트 전용 컴퓨터 폴더를 WebLink와 연결하고, 로컬 파일 가져오기·내보내기를 할 수 있음
- 로컬 폴더는 브라우저 권한으로만 기억하며 GitHub Desktop의 저장소를 연결하면 파일을 커밋·푸시해 협업할 수 있음. GitHub 자동 업로드나 Google Drive 연동은 아직 없음
- 로컬 폴더 동기화는 서버 초안 버전을 먼저 확인해 충돌 시 로컬 파일을 덮어쓰지 않으며, `.git`, `.env`, 개인 키 등은 복사하지 않음
- 프로젝트 편집 중 실행·리비전·버전 저장·ZIP·탐색 동작은 초안을 먼저 저장하며, 변경 없는 초안과 동일 리비전의 저장 버전은 중복 생성하지 않음
- 프로젝트 카드/작업 화면에서 프로젝트 전체를 삭제하고, 저장 버전은 개별 삭제 가능. 프로젝트 SQLite Docker 볼륨 정리는 worker 큐에서 재시도
- 저장된 프로젝트 파일 ZIP 내려받기, 사용자 프로젝트 접근 검증 및 환경 비밀 파일 제외
- 프로젝트 ZIP 가져오기, 압축 1.5MB·압축 해제 1MB·50파일 제한, UTF-8 텍스트 및 경로 검증, 중복·비밀 파일 차단
- ZIP 이동은 저장된 프로젝트 소스만 포함하며, 프로젝트별 SQLite 데이터베이스·리비전·버전·OAuth 토큰·서버 환경 설정은 포함하지 않음
- 네트워크가 차단된 컨테이너에서 Python 프로젝트 실행
- 프로젝트별 영구 SQLite 저장 공간
- API·페이지 처리·오류 재시도와 외부 앱 연결을 연습하는 학습용 API
- Gemini 기반 실행 오류 힌트
- Google Sheets 계정 연결, 범위 미리보기, 프로젝트 코드에서 시트 값 읽기
- Google Sheets 요청 실패 원인을 범위 오류, 계정 권한, API 미사용 설정, 만료 연결, 요청 한도로 구분해 한국어로 안내
- Google Sheets 범위 읽기부터 행 정리와 프로젝트 SQLite DB 동기화까지 이어지는 실습 포함 (총 37개 수업)
- Sheets 미리보기 후 프로젝트 생성, 코드 저장, 첫 SQLite 동기화 실행까지 이어지는 연결 화면 추가. 가져오기 전에 열 제목·행 모양·첫 열 고유 키를 검사하고, 시트 주소나 범위를 수정하면 과거 미리보기는 폐기
- 생성 예제는 행 키를 사용해 중복을 갱신하고, 임시 표에서 먼저 검증한 뒤 트랜잭션으로 최신 시트 전체를 반영. 빈 데이터·중복 키·잘못된 행은 기존 DB를 보존하고 중단
- Sheets 블록 코드를 프로젝트로 이어 만들 때, 미리보기에서 확인한 스프레드시트 ID와 범위를 새 프로젝트 코드에 자동 반영
- 연결 화면에서 Google Sheets 전체 주소에서 ID를 추출해 미리보기하고, 유효하지 않은 주소는 안내 문구로 알림. 미리보기 표는 첫 행을 열 제목으로 구분

## Google Sheets 연결 확인 결과

2026-09-28 로컬 환경에서 사용자의 Google OAuth 계정 연결을 완료했다. 테스트용 Google Sheets에 가상 샘플 표를 입력하고 WebLink의 연결 화면에서 한국어 기본 탭의 `시트1!A1:D4` 범위를 읽어 네 행의 데이터를 확인했다.

프로젝트 코드에서는 다음 함수를 사용할 수 있다.

```python
from weblink_api import get_google_sheet

sheet = get_google_sheet("SPREADSHEET_ID", "'시트1'!A1:D4")
rows = sheet["values"]
print(rows)
```

현재 연결은 읽기 전용이다. 프로젝트가 값을 읽는 기능까지 있으며, 데이터베이스에 자동 저장하거나 계속 동기화하거나 Google Sheets에 다시 쓰는 기능은 아직 없다.

## 보안 및 권한 범위

- Google OAuth는 Sheets 읽기 전용 권한을 요청한다.
- Google refresh token은 Fernet 키로 암호화해 PostgreSQL에 저장한다. `.env`와 암호화 키는 Git에 올리지 않는다.
- 학생 코드 실행 컨테이너는 네트워크가 차단돼 있다. Google 연결이 있는 실행에서만 별도의 고정 목적 연결 서비스가 Google token 및 Sheets API에 접속한다.
- Google Sheets 권한은 특정 셀 범위만으로 제한되지 않는다. 범위 입력은 한 번의 읽기 요청에 사용할 범위이며, 실제 OAuth 권한은 연결한 Google 계정이 접근할 수 있는 스프레드시트에 적용된다.
- 로컬 OAuth 앱은 개발/테스트 용도다. Google Cloud 테스트 사용자와 외부 앱 설정이 필요할 수 있다.

## 로컬 확인 상태

- WebLink web, API, worker, PostgreSQL이 Docker Compose로 실행된다.
- API와 worker 상태 확인에서 정상 상태를 확인했다.
- 데이터베이스 버전은 이번 작업에서 직접 확인하지 않음. 저장소의 최신 마이그레이션은 Google Sheets 학습 `20260929_0028`~`20260929_0031`, 공동 프로젝트 파일 `20260929_0032`, 작업 보드 `20261001_0033`, 작업 우선순위·마감일 `20261001_0034`, 작업 댓글·활동 기록 `20261001_0035`, 작업 체크리스트 `20261001_0036` 순서이며 API 컨테이너가 시작될 때 미적용 마이그레이션을 순서대로 적용함
- 프론트엔드 TypeScript 및 Vite 프로덕션 빌드 성공
- API 연결 코드 Python 구문 검사 성공
- 실제 Google Sheets 범위 읽기 성공
- 자동화 테스트 전체 실행 여부: 이번 연결 작업에서는 실행하지 않음
- 파일 탐색기 폴더 이름 변경·삭제, 팀원 권한 및 공동 초안 자동 반영 기능: 코드 반영 후 통합 수동 확인 대기
- 이번 작업 보드 변경은 빌드·테스트하지 않았으며, 컨테이너 재빌드 후 활동 알림 갱신·읽음 표시·작업 이동, 내 마감 알림 바로가기, 기존 검색·필터·댓글·체크리스트 기능을 수동 확인해야 함
- 프로젝트 대시보드·최근 활동·README Markdown/HTML 미리보기와 구역 탐색 UI는 빌드·테스트하지 않음. 활동 이동·읽음 표시, HTML 허용 태그와 위험한 태그·링크 차단, README 생성 후 편집·초안 저장, 기존 입력·실행 결과 유지 확인 필요
- 학습·연결 화면 반응형 간격과 모바일 레이아웃 변경은 빌드·테스트하지 않음. 모바일에서 코스 목록이 본문 위에 쌓이는지, 스프레드시트 입력이 한 열로 전환되는지 확인 필요

- Google 계정 로그인 및 Drive 파일 가져오기

Google 로그인과 Drive 파일 가져오기는 이후 단계 후보이다. 구현할 때는 로그인 권한과 Drive 파일 권한을 분리하고, Google Picker에서 사용자가 직접 고른 파일만 가져오는 흐름을 우선 검토한다.

## 시작 및 설정

프로젝트 루트에서 `.env.example`을 참고해 실제 `.env`를 준비한 뒤 실행한다.

```powershell
docker compose up --build
```

- Web: <http://localhost:5173>
- API readiness: <http://localhost:8000/health/ready>
- Google Sheets redirect URI: `http://localhost:8000/api/v1/connections/google/oauth/callback`

실제 비밀값이 든 `.env`는 공유하거나 커밋하지 않는다. OAuth 설정과 암호화 키는 `.env.example`의 빈 항목에 대응하도록 `.env`에 따로 저장한다.

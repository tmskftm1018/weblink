# 디자인 작업용 기능 정리

기준일: 2026-10-29. 이 문서는 기능과 문구의 전달용이며 디자인/CSS 변경이 아니다.

## 사이트가 하는 일

“코드를 작성할 수 있지만 앱으로 연결하기 어려운 학습자가, 화면·API·DB를 연결하는 과정을 배우는 실습 사이트.”

가장 먼저 보여 줄 흐름은 과목·수준 선택 → 목표와 확인 조건 → 코드 실습 → 실패 항목과 힌트 → 수정·재검사 → 게시판 완성이다. 프로젝트/팀/외부 연결 기능보다 이 흐름을 앞세운다.

## 현재 기능

| 구역 | 유지해야 할 동작 |
| --- | --- |
| 과목·난이도 | 웹 화면/서버·API/DB 복수 선택, 입문/기본/경험자 선택, 서버 저장과 설정 충돌 보호 |
| 학습 홈 | 이어 하기, 선택 과목/전체 과정 전환, 복습 추천, 현재 저장본의 완료 진도 |
| 미션 | 결과물·정상 결과·수준별 단계 안내, 실제 코드 실행, 개념 선택, 선택 메모 |
| 확인 | 현재 답안 저장 후 검사, 실패 항목 안내, 단계별 힌트, 통과 후 다음 미션 |
| 재확인 | 변경된 선수 수업과 미완료 선수 수업을 구분, 접근 가능한 수업으로 이동, 현재 실습 재확인 안내 |
| 보존 | 자동 덮어쓰기 없는 복구·충돌 비교, 기존 미완료 답안의 새 형식 전환, 완료 기록 보존 |
| 결과물 | M10/M12의 통과한 저장 코드를 개인 프로젝트·ZIP 앱으로 가져오기, 반복 생성 시 같은 프로젝트 사용 |

난이도별 제공 코드·안내·필수 응용 범위가 다르며 기능 확인 기준은 공통이다. 세 개의 독립된 강좌가 완성됐다는 표현은 사용하지 않는다. 자유 서술의 문장 품질이나 교육 효과를 AI가 자동 평가한다고 표현하지 않는다.

## 상태를 구분해야 하는 부분

- NOT_STARTED / DRAFT / NEEDS_WORK / PASSED / STALE은 서로 다르다. STALE은 이전 성공 기록이 있지만 현재 기준 재확인이 필요하다는 의미다.
- 앞 수업이 미완료면 먼저 해당 수업을 확인한다. 이미 완료한 앞 수업의 내용이 바뀐 경우 현재 코드를 살펴보고 현재 실습을 다시 확인한다.
- 코드 실행기 장애는 학습자 오답으로 표시하지 않는다.
- 선택 메모는 접어서 둘 수 있으며 쓰지 않아도 제출할 수 있다. M11 실패 재현, M12 연결 원리 설명은 남아 있다.
- 이미 저장한 과제의 난이도는 경로 설정만으로 바뀌지 않는다. 완료한 수업은 형식 전환 대상이 아니다.

## 홈페이지 문구 정리 시 참고

현재 홈에는 과거의 ‘블록 학습’, ‘Python 프로젝트’, ‘Google Sheets’ 중심 문구가 남아 있다. 화면 디자인 작업 때 현재 학습 목적에 맞춰 다음 표현으로 정리할 수 있다.

- 대표 소개: **배운 코드를 연결해, 작동하는 앱으로**
- 설명: **화면의 입력이 API를 거쳐 DB에 저장되는 과정을 미션으로 연습합니다. 실행 결과와 오류를 확인하며 작은 게시판을 완성하세요.**
- 핵심 기능: **나에게 맞는 과목·수준 / 만들며 배우는 미션 / 결과를 보고 고치기 / 내 앱으로 이어가기**
- 예시 흐름: **목표 확인 → 화면 작성 → API 연결 → DB 저장 → 오류 수정 → 다른 앱에 적용**

Google 로그인·외부 연동·공개 운영 준비는 현재 범위에서 보류한다. 학습자는 원하는 AI 사이트나 CLI를 선택적으로 사용하며 AI API 키 등록을 필수로 안내하지 않는다.

## 검증의 범위

세 수준의 12개 미션을 로컬 HTTP와 실제 등록 실행기로 완주했다. 내보낸 게시판은 브라우저 등록·조회·재시작 후 DB 유지, 메모장은 브라우저 등록·새로고침 복원을 확인했다. 모든 미션의 브라우저 완주나 실제 학생의 학습 효과 검증과는 구분한다. 세부 증거는 VERIFY_REPORT.md를 따른다.


## 2026-10-30 기능 후속

홈의 기능 카드 이동만 구분했다. 로그인 상태에서 LEARN → 새 학습 홈, CONNECT → 연결 앱, BUILD/COLLABORATE → 프로젝트 목록이다. 외형·기존 문구는 유지했다. 과거 블록/Python/Google 중심 소개는 위 제안대로 별도 디자인 작업 때 정리한다. 학습 설명은 새 실습 형식과 과거 작성형 기준을 분리했으며 공통 M01/M02는 난이도별 코딩 과제로 표시하지 않는다.


실행 근거 표시 후속: 제출 피드백의 ‘저장본 vN의 실행 근거 보기’는 기본 접힘이며 읽기 전용이다. 접기를 펼쳐도 실행 요청을 보내지 않는다. 코드가 바뀐 상태나 STALE 결과를 현재 결과처럼 표시하지 않아야 한다. React 스냅샷을 동작하는 앱 미리보기로 소개하지 않는다. 실패 재현본의 의도된 기능 실패와 실행 환경 장애를 구분한다.

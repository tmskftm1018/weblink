# WebLink 학습 시스템 구현 계획

기준일: 2026-10-19
설계 기준: `WebLink_통합학습시스템_최종설계서_v1.1.pdf`
현재 상태: G0 기준선 일부 확보, G1 진행 중. 의존성/잠금파일 복구 후 API·학습 테스트 44개 및 웹 빌드 통과. 실제 PostgreSQL/worker 검증과 새 학습 UI·평가 엔진은 미완료.

## 제품 결정을 먼저 고정

1. **학습은 AI API 호출 없이 완주 가능해야 한다.** 수업, 힌트, 객관적 검사, 진도는 WebLink가 제공한다. 학습자는 원하면 자신의 기기에서 공식 CLI를 실행하거나 AI 웹사이트를 직접 이용한다.
2. **CLI/사이트로 보낼 정보는 수동·선택형이다.** WebLink는 CLI 세션, 쿠키, 계정 토큰, 유료 구독 자격증명을 읽거나 서버로 전달하지 않는다. 선택된 수업 맥락은 미리 보고 동의한 뒤에만 복사한다.
3. 기존 Gemini API 디버깅 힌트는 기존 프로젝트 도구로 분리한다. 새 수업의 도움·평가를 대신하지 않고, API 키가 없어도 수업이 동일하게 진행된다.
4. 플랫폼 PostgreSQL과 사용자별 학습 자료의 저장 경계를 보존한다. 운영 DB를 SQLite로 교체하지 않는다. 미니 게시판에서 배우는 SQLite는 교육 프로젝트의 격리된 워크스페이스 안에서만 다룬다.
5. 기존 수업과 사용자 진도는 즉시 삭제하지 않는다. 새 코스 지도에 명시적으로 연결하거나 기존 코스 보관 영역으로 옮기고, 기존 ID 및 완료 이력을 유지한다.
6. 기존 일반 프로젝트 편집·실행기는 코스 전용 워크스페이스와 경계를 유지한다. HTML/JS 실습 파일을 React 프로젝트로 덮어쓰지 않는다.

## 제안하는 학생 경로

```text
목표/경험 진단
  → 필요한 C00~C05 사고 기초
  → 웹 풀스택 코스 WEB-FS-01 (M01~M12)
       필요한 순간에 B 브리지 → 원래 미션/개정으로 복귀
  → 핵심 기능 검사 + 개념 확인 + 주요 지점의 전이 과제
  → 독립 변형·설명·포트폴리오

원하는 경우: 학생이 자신의 CLI 또는 AI 사이트를 별도로 열어 선택된 맥락을 수동 제공
```

현재 기존 5개 코스/37개 수업은 이 경로와 동일한 교육 단위가 아니다. 새 코스의 한 과정으로 뭉치지 않고, 각 레슨의 개념과 선행 지식을 검토해 재사용 가능한 콘텐츠만 매핑한다. 외부 앱/API 연결 수업은 게시판 코스 이후의 선택형 응용 카탈로그로 남길 수 있다. 중복되거나 맞지 않는 옛 노출 항목은 보관 처리하되 데이터 삭제는 하지 않는다.

## 권장 순서와 주요 기술 결정

1. **G0 완료:** API 테스트용 의존성/잠금 문제와 Docker 검증 경계를 해결하거나 막힌 근거를 기록한다. 사용자 데이터는 조회·초기화하지 않는다.
2. **콘텐츠 계약:** `course_id`, canonical lesson ID, content/rubric versions, prerequisites, test/concept/transfer/hint IDs, target files, recovery, next를 검증 가능한 JSON 모델로 둔다. 초기에는 전체 45차시 카탈로그를 모두 실행 가능하다고 표시하지 않는다.
3. **진도/증거:** `LearningEnrollment`와 `LearningAssessmentEvidence`를 기존 모델과 분리된 추가형 저장으로 연결한다. 코드 저장은 기존 `Project/ProjectRevision`을 재사용하고, 판정은 추후 WebLink의 버전 있는 신뢰 검사 코드만 수행한다.
4. **M01~M04:** 가입된 계정별 저장·복귀, 요구사항/데이터 흐름 산출물, 접근성 폼, 공백 검증을 만든다. HTML/DOM 실습과 이후 React 워크스페이스를 분리한다.
5. **M05~M12:** 단계마다 테스트를 먼저 연결해 실제 증거를 만든 다음, React/API/SQLite 흐름을 잇는다.
6. **C/B 및 legacy 매핑:** 이미 있는 레슨 설명·예시 중 맞는 것은 출처/ID를 남겨 재사용하고, 새 수업 문구는 한국어로 작성한다. 동일 개념을 두 번 강제하지 않는다.
7. **CLI 안내와 내보내기:** Codex/Gemini 공식 가이드를 구현 시점에 확인한다. AI를 WebLink 백엔드에서 호출하거나 사용자 자격증명을 수집하는 기능은 만들지 않는다.
8. **종단 검증/정리:** 초보자·경험자·AI 미사용 경로, 소유권/사용자별 격리, 복구·재시작, 오류 경로를 검증하고 `VERIFY_REPORT.md`, `NEXT_STEPS.md`를 갱신한다.

## 보류·승인 경계

- 기존 코스/레슨/진도 행 삭제, DB 초기화, 기존 진행도 강제 변환은 하지 않는다. 의미 있는 자동 매핑이 불가능하면 옛 이력은 그대로 보존한다.
- 운영 공개, 외부 과금, 권한 축소, 저장소 강제 수정/푸시는 요청하지 않는다.
- 미검증 실행기 변경으로 안전을 약속하지 않는다. Docker worker 권한·네트워크 허용 경계는 G5 전용 검증 항목이다.
- 교육 효과, 학생 사용성, 전반적 보안은 실제 사용자 연구/독립 보안 검토 없이 입증했다고 표현하지 않는다.

## 2026-10-20 추가 반영 · SQLite 저장과 API 재시작
